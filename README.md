  # Mistvale Tea Co.

  A premium tea storefront built as a static e-commerce landing page for a boutique tea brand.

  ## Overview

  Mistvale Tea Co. is a fictional tea brand inspired by Darjeeling heritage and modern premium retail. This project focuses on creating a polished online shopping experience with product discovery, a working cart flow, responsive design, and a premium brand presentation.

  ## Features

  - Responsive storefront optimized for mobile and desktop
  - Product browsing with search, category filtering, and sorting
  - Shopping cart with quantity validation, coupon support, and shipping calculations
  - Delivery pincode checking and validation feedback
  - Premium brand styling aligned with the project design system
  - Accessible interactions for keyboard and screen-reader users
  - SEO-friendly layout and metadata

  ## Project Structure

  - `index.html` — Main storefront page with HTML, CSS, and JavaScript
  - `images/` — Brand assets, product visuals, and hero graphics
  - `BRAND.md` — Brand and product information used for styling and messaging
  - `NOTES.md` — Implementation notes and decisions

  ## Run Locally

  Because this is a static front-end project, you can run it directly in a browser:

  1. Open `index.html` in your browser

  ## Notes

  This project is a front-end assessment built using plain HTML, CSS, and JavaScript without frameworks or a build step.
